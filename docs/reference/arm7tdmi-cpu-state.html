ARM7TDMI CPU State (GBA)

Source of truth: GBATEK — ARM CPU Core and the ARM7TDMI Technical Reference Manual. Verify everything here against those.

Registers (r0–r15)

RegNameRole
r0–r12—General purpose
r13SPStack pointer
r14LRLink register (return address; BL writes here)
r15PCProgram counter. Reads are +8 (ARM) / +4 (THUMB) ahead due to pipelining

Banked copies: FIQ has its own r8–r14; IRQ/SVC/ABT/UND have their own r13–r14. Switching mode swaps them in automatically.

Go bit-manipulation idioms used with the CPSR

const (
    flagN uint32 = 1 << 31
    flagZ uint32 = 1 << 30
    flagC uint32 = 1 << 29
    flagV uint32 = 1 << 28
    flagT uint32 = 1 << 5
    modeMask uint32 = 0x1F
)

c.Has(flagC)          // test:  c&flag != 0
c.Set(flagZ)          // set:   c |= flag
c.Clear(flagT)        // clear: c &^= flag
Mode(c & modeMask)    // extract low 5 bits
