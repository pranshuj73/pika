The immediate trick (I=1)

operand2's low 12 bits split into an 8-bit value (bits 7–0) and a 4-bit rotate (bits 11–8). The real operand is the value rotated right by 2 × rotate bits. Why? A plain 8-bit constant can't express numbers like 0x00F00000 — but rotation reuses those 8 bits at any even position. Consequence: most 32-bit constants are not directly loadable; assemblers pick a representable rotated form or build them with multiple instructions.

Rotate right of 0 means the operand is just the 8-bit value, zero-extended. Start there.

Patterns to remember

  • TST/TEQ/CMP/CMN never write Rd — they exist purely to set flags (that's why CMP + condition codes replaces x86's compare-and-jump fusion). If S=0 they would be useless; the encoding requires S=1 for them.
  • MOV/MVN ignore Rn — there is no first operand; the field is a don't-care.
  • The odd opcode bit (bit 21) is a modifier: 1 = bitwise NOT of op2 (AND→BIC, MOV→MVN) or a reversed subtraction (SUB→RSB).
  • Logical ops (AND/EOR/ORR/BIC/MOV/MVN/TST/TEQ) don't set V; arithmetic ops (±, with carry) set all four. Logical ops set C from the barrel shifter (later lesson).
